# 开发纪律补充（references · R6-ts-developer）

> 固化来源：dshALICodeReview 交接文档 §十~§十六 + skill_improvement + 最终联调复盘（2026-09-21）。

## §十 沙箱权限判断纪律
1. 操作被拒时**先判断目标是否在工作区内**：是 → **不应升级**（workspace-write 已够），重查真实原因（如 spawn EPERM 属子进程管道限制，非文件权限）；否（harness checkout/npm 全局/生产 DSH_HOME）→ 才升级一次。
2. **不要不停尝试/盲目升级**；同一问题连续卡住（≥2 次尝试无进展）即**终止**，向用户说明理由并征求建议。

## §十一 报错即停纪律（避免 token 浪费挖源头）
1. 工具报错时，先判断是否"版本过期/环境问题"——提示用户"可能装了旧版，请重装/升级"，**不要自行翻源码找根因**。
2. 需要查根因时，**先问用户**是否要深挖；默认报错即止、把现象+已定位线索给用户。
3. 版本相关报错（行为与最新代码不符）优先让用户确认安装版本，而非考古。

## §十二 超时设计纪律
1. **禁止自行定一个超时时间**。任何超时设计前，**先查底层**（工具层 timeoutMs 上限、接口/服务执行预算、spawnTerminal graceMs 等）。
2. 超时时间基于**底层限制 + 实测耗时**制定（留余量），不拍脑袋。
3. 明确**超时后行为**：后台继续/中断/可恢复；接口超时要有降级路径（转后台 + 状态查询 + 手动获取）。

## §十三 Bug 修复纪律（先罗盘 task + 不越界改目标）
1. **修 bug 前先"罗盘 task"**：列出任务拆解，阐述方案、输入/输出（预期行为、改哪些文件、输入、验收口径），再动手。
2. **原始需求没明确说的，就不要动最终实现的目标**——不越界扩展、不顺手重构未要求部分；超范围改动先问用户。

## §十四 手动终止 vs 自动崩溃区分（防 token 爆炸）
1. **区分"用户手动终止"与"程序自动崩溃"**：显式标记 `userCancelled`（手动）vs `error`（自动）。
2. **手动终止 → 不要自动重试**：提示用户"已手动中止，请勿自动重试"。
3. **自动崩溃 → 最多重试一次**；仍失败则停止并上报。

### 需求变化及时记录
- **需求有变化时，及时先更新 task 文件做记录**（改动点、原因、影响范围），再继续开发；保持 task/文档与实现同步。

## §十五 测试环境版本更新纪律
1. **更新测试环境必做清单**：① bump 版本号 ② 清理旧 node_modules 条目/确认安装版本 ③ **告知用户强制刷新浏览器**（Ctrl+Shift+R）加载新 client bundle ④ 重启后验证启动日志版本行。
2. **可见版本标识（必做）**：插件 apply 时 `console.log('[插件名] apply v<版本> <关键配置>')`；状态接口与 UI 带 `version`；UI 卡片显示版本角标。
3. **log 展示纪律**：关键路径 console.log/error（启动版本、错误栈、手动中止标记、评审异常退出）；错误必须留痕可查。

## §十六 手动终止后 AI 仍判断（skill/提示词层强约束）
- 工具返回 `userCancelled`/`cancelledByUser` 即**停止**——不重试、不排查、不修改代码，直接向用户确认是否重新发起。

## 实现纪律（skill_improvement §6）
1. **环境相关命令固定 workdir**（如 npm pack 在包目录）。
2. **状态机并发边界**（连续调用竞态，同步重置）。
3. **外部副作用**（规则/配置文件）必须 per-run 或可还原（写前备份，验证完还原）。
4. **工具输出 JSON 序列化自测**：返回对象先 `JSON.stringify` 往返（无 undefined），再交给工具层。
5. **字段命名与 client 一致**：同一状态源字段形状一致（API↔Client 断言锁死）。
6. **结束路径必 `await terminate()`**：无残留进程。
7. **版本标识三处**（日志/状态/UI）。
8. **打包前本地单测覆盖契约**，减少"打包→重装→重启→实测"循环。

## 验收
- 沙箱升级有"目标在工作区外"依据；报错默认停止+提示用户；超时有底层限制依据；bug 修复有 task 罗盘；手动终止有"勿重试"信号；需求变化有 task 记录；更新后有版本行日志+可见版本标识；工具输出 JSON 无损；字段一致；无残留进程。
