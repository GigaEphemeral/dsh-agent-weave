## 〇、Phase F 实测结论 → MVP-2 设计基线

**MVP-2 的所有设计决策都基于以下实测结论，不再有未验证的假设。**

| 实测结论 | 来源 | 对 MVP-2 的强制约束 |
|---|---|---|
| **`sendMessage(sender, targetId, content, options)` 是当前 API**；`followup`/`reportFrom` 不存在 | RES.3 | 消息总线（MVP-3）用此 API；MVP-2 不涉及 |
| **`startContinuable(spec)` 是唯一续接入口**；`prepareContinuable` 方法存在即能力 | RES.3 | 子代理节点用 `ctx.subagents.start`；MVP-2 用 `addSubagent` |
| **`agentRouteDefaults` 存在且生效** | FIX.4 + RES.3 | 角色 provider 复用已注册 model，无需重复配置 |
| **`capabilities.depthLimit` 是布尔能力标志**；数字走 `RoleProfile.depthLimit` → `start()` 的 `maxDepth` | FIX.5 | 角色 YAML 的 `max_concurrent_children` 映射为 `maxDepth`（**深度，非广度**） |
| **`dsh-subagent` 无内置并发闸** | RES.5 | **引擎层必须自建全局并发闸**（acquire/release + try/finally） |
| **裸 `setTimeout` 在热重载后泄漏**；`ctx.effect()` 包装正常清理 | RES.4 | 所有非 Cordis 资源必须 `ctx.effect()` 注册；热重载测试入门禁 |
| **`ctx.llm` 无 `complete` 方法**；正确 API 是 `ctx.llm.stream()`；TokenUsage 在 `assistant/message.data.usage` | RES.1 | Token 采集点在**节点层**（读 session `data.usage`），MVP-2 只预留接口 |
| **`dsh-state-graph` 8 项设计可直接采用** | RES.10 | 增量补丁模型、迭代熔断、checkpoint 回调、审批门、边模型、事件契约、静态校验、服务形态 |
| **图版本迁移采用 AgentGit 快照 + CVC 内容寻址思想** | RES.8 | `graphVersion` 双字段（semver + hash），恢复时"相同→恢复/不同→拒绝"最小闭环 |
| **产物路径必须从 `ctx` 取，禁止 `process.cwd()`** | FIX.6 | checkpoint 契约强制约束 |
| **角色 Skill 需"核心能力 + 任务适配层"分离** | FIX.7 | `SubagentNodeOptions.provider` 预留 `{roleRef, adapter}` 扩展点 |


## 一、阶段定位与设计目标

### 1.1 为什么 MVP-2 是质变点

MVP-1 用 workflowEngine 证明了"角色能协作"，但那是**脚本式**的：

| MVP-1 的边界 | MVP-2 的突破 |
|---|---|
| `workflowEngine.agent(prompt, opts)` 的 `provider` 是 LLM 路由覆盖 | **自研 StateGraph 直驱 subagents**，节点通过 `roleRef` 引用角色 |
| 固定串行 R1→R2→…→R8 | **图 DSL**：节点 + 边（seq/cond/loop），可配置 |
| 无循环 | **循环回退 + 迭代熔断** |
| 状态在脚本变量里 | **引擎原子合并** + 冲突 `reject-on-conflict` |
| 无恢复 | **节点级 checkpoint** |

### 1.2 设计目标（基于实测修订）

| # | 目标 | 验收标准 | 实测依据 |
|---|---|---|---|
| **G1** | 图 DSL 可描述条件边与循环 | YAML 定义含循环的图，通过 Schema + 静态验证 | RES.10 §三.7 |
| **G2** | 引擎正确执行条件边和循环回退 | 含循环 DSL 跑通，循环退出 + 熔断双生效 | RES.10 §一.3 |
| **G3** | checkpoint 契约支撑恢复 | 节点级落盘，带 `graphVersion`；中断后能从最近 checkpoint 重建 | RES.8 §三.2 |
| **G4** | 路由逻辑零 Token 可测 | BDD/mock 测试全绿，零 LLM 调用 | RES.1 |
| **G5** | 资源生命周期合规 | 7 项检查清单全部通过；热重载后无泄漏 | RES.4 §五 |
| **G6** | 引擎层全局并发闸生效 | 超限拒绝激活；acquire/release 成对 | RES.5 §四 |

## 四、任务详细拆解（基于实测）

### T1：引擎内部类型定义

**目标**：定义 StateGraph 引擎的所有内部类型，作为后续模块的契约基础。

**交付物**：`src/l2-engine/types.ts`

**必须包含的类型**（基于 RES.10 §一.1/2/4 的实际签名）：

```typescript
import type { Context } from '@deepseek-ai/cordis';

/** 节点处理器：接收 State 和上下文，返回 Partial<State>（RES.10 §一.2） */
export type NodeHandler<T> = (
  state: T,
  ctx: GraphNodeContext<T>,
  signal?: AbortSignal,
) => Promise<Partial<T>>;

/** 条件处理器：返回下一个节点名 / 并行目标数组 / "__END__"（RES.10 §一.1） */
export type ConditionHandler<T> = (
  state: T,
  ctx: GraphNodeContext<T>,
  signal?: AbortSignal,
) => string | string[] | '__END__' | Promise<string | string[] | '__END__'>;

/** 节点执行上下文 */
export interface GraphNodeContext<T> {
  /** Cordis 上下文 */
  ctx: Context;
  /** 当前图实例 ID（引擎生成：graph-{ts}-{rand}） */
  graphId: string;
  /** 图版本（RES.8 §三.1） */
  graphVersion: string;
  /** 事件发射器（RES.10 §一.7 的 graph/* 事件） */
  emit: (event: TrajectoryEvent) => void;
  /** 结构化日志 */
  logger: Logger;
  /** checkpoint 回调 */
  checkpoint: CheckpointCallback<T>;
  /** 当前迭代次数 */
  iteration: number;
  /** 审批上下文（RES.10 §一.5：审批门需要 agent） */
  agent?: Agent;
}

/** 轨迹事件（RES.10 §一.7 的 graph/* 事件契约） */
export interface TrajectoryEvent {
  type: 'graph/start' | 'graph/node-start' | 'graph/node-end'
      | 'graph/node-error' | 'graph/error' | 'graph/end'
      | 'graph/checkpoint-written' | 'graph/loop-iteration';
  graphId: string;
  node?: string;
  timestamp: number;
  durationMs?: number;
  data?: Record<string, unknown>;
}

/** 图执行结果（RES.10 §一.2 的 GraphExecutionResult 形态） */
export interface GraphExecutionResult<T> {
  graphId: string;
  success: boolean;
  finalState: T;
  trajectory: TrajectoryEvent[];

/** 运行选项（RES.10 §一.4/5：checkpoint + agent） */
export interface RunOptions<T> {
  /** checkpoint 回调（必需，RES.10 §一.4） */

  /** 审批上下文（RES.10 §一.5：审批门需要） */
  agent?: Agent;
  /** 中止信号 */
  signal?: AbortSignal;
  /** 初始迭代次数（默认 0） */

/** checkpoint 载荷（RES.10 §一.4 + RES.8 §三.1 增加 graphVersion） */

  graphId: string;
  /** 图 DSL 版本（RES.8 §三.1 双字段：semver + hash） */
  graphVersion: string;
  /** DSL schema 内容哈希（RES.8 §三.1，CVC 内容寻址思想） */
  graphSchemaHash: string;
  node: string;
  state: T;
  iteration: number;
  timestamp: number;
}

/** checkpoint 回调（RES.10 §一.4：回调不应抛错） */
export type CheckpointCallback<T> = (
  payload: CheckpointPayload<T>,
) => Promise<void>;

// === 图定义规格（与 graph-definition.ts 共享） ===

export interface GraphDefinitionSpec {
```

### T2：图 DSL Schema（Zod）

```typescript

/** 节点 ID 正则（RES.10 §二.5：dsh-agent-graph 用 ^[a-z][a-z0-9_-]*$） */
const NODE_ID_PATTERN = /^[a-z][a-z0-9_-]*$/;

export const GraphNodeSpecSchema = z.object({
  id: z.string().regex(NODE_ID_PATTERN, '节点 ID 必须匹配 ^[a-z][a-z0-9_-]*$'),
  roleRef: z.string().optional(),
  promptTemplate: z.string().optional(),
  nodeType: z.enum(['role', 'condition', 'approval']),
});

export const GraphEdgeSpecSchema = z.object({
  from: z.string().min(1),
  to: z.string().min(1),
  type: z.enum(['seq', 'cond', 'loop', 'parallel']),
  when: z.string().optional(),
  maxIter: z.number().int().positive().optional(),
}).refine(
  (edge) => edge.type !== 'cond' || edge.when !== undefined,
  { message: 'cond 边必须有 when 字段' },

  { message: 'loop 边必须有 maxIter 字段' },
).refine(
  (edge) => edge.from !== edge.to || edge.type === 'loop',
  { message: '自环边只允许 loop 类型（RES.10 §二.5）' },
```

```typescript
import type { GraphDefinitionSpec } from './types.js';

export interface ValidationResult {
  valid: boolean;
  errors: Array<{ path: string; message: string }>;
}

/** 状态字段白名单（用于 when 表达式校验） */
const STATE_FIELDS = new Set([
  'messages', 'current_phase', 'active_agent', 'task_queue',
  'artifacts', 'quality_gate_status', 'retry_count', 'max_iterations',
]);

export interface ValidatorContext {
  registeredRoles: Set<string>;
}

export function validateGraph(
  spec: GraphDefinitionSpec,
  ctx: ValidatorContext,
): ValidationResult {
  const errors: Array<{ path: string; message: string }> = [];

  // 1. roleRef 必须已注册
  for (const node of spec.nodes) {
    if (node.nodeType === 'role' && node.roleRef) {
      if (!ctx.registeredRoles.has(node.roleRef)) {
        errors.push({
          path: `nodes.${node.id}.roleRef`,
          message: `角色未注册: ${node.roleRef}`,
        });
      }
    }
  }

  // 2. cond 边的 when 引用字段必须存在
  for (const edge of spec.edges) {
    if (edge.type === 'cond' && edge.when) {
      const referencedFields = extractFields(edge.when);
      for (const field of referencedFields) {
        if (!STATE_FIELDS.has(field)) {
          errors.push({
            path: `edges.${edge.from}->${edge.to}.when`,
            message: `引用了未知状态字段: ${field}`,
          });
        }
      }
    }
  }

  // 3. 入口可达性（BFS）
  const reachable = computeReachable(spec.entryPoint, spec.edges);
  for (const node of spec.nodes) {
    if (!reachable.has(node.id)) {
      errors.push({
        path: `nodes.${node.id}`,
        message: `节点从 entryPoint 不可达`,
      });
    }
  }

  // 4. 环检测（RES.10 §二.5：Kahn 算法 + 确定性拓扑序）
  const cycleResult = detectCycles(spec.nodes, spec.edges);
  if (cycleResult.hasCycle) {
    for (const nodeId of cycleResult.cycleNodes) {
      errors.push({
        path: `nodes.${nodeId}`,
        message: `节点处于环中`,
      });
    }
  }

  // 5. 自环（Schema 已做，二次确认）
  for (const edge of spec.edges) {
    if (edge.from === edge.to && edge.type !== 'loop') {
      errors.push({
        path: `edges.${edge.from}->${edge.to}`,
        message: `自环边只允许 loop 类型`,
      });
    }
  }

  return { valid: errors.length === 0, errors };
}

/** 从条件表达式提取字段名 */
function extractFields(expr: string): string[] {
  const fields: string[] = [];
  const regex = /state\.(\w+)/g;
  let match: RegExpExecArray | null;
  while ((match = regex.exec(expr)) !== null) {
    fields.push(match[1]);
  }
  return fields;
}

/** 从入口计算可达节点（BFS） */
function computeReachable(
  entry: string,
  edges: Array<{ from: string; to: string }>,
): Set<string> {
  const reachable = new Set<string>([entry]);
  const queue = [entry];
  while (queue.length > 0) {
    const current = queue.shift()!;
    for (const edge of edges) {
      if (edge.from === current && !reachable.has(edge.to)) {
        reachable.add(edge.to);
        queue.push(edge.to);
      }
    }
  }
  return reachable;
}

/**
 * 环检测（RES.10 §二.5：Kahn 算法 + id 排序 frontier 得确定性拓扑序）
 *
 * 注意：loop 边是合法的环（有 maxIter 兜底），不视为错误。
 * 只有非 loop 边的环才是错误。
 */
function detectCycles(
  nodes: Array<{ id: string }>,
  edges: Array<{ from: string; to: string; type: string }>,
): { hasCycle: boolean; cycleNodes: string[] } {
  // 只考虑非 loop 边
  const nonLoopEdges = edges.filter((e) => e.type !== 'loop');

  const inDegree = new Map<string, number>();
  const adjacency = new Map<string, string[]>();

  for (const node of nodes) {
    inDegree.set(node.id, 0);
    adjacency.set(node.id, []);
  }

  for (const edge of nonLoopEdges) {
    adjacency.get(edge.from)?.push(edge.to);
    inDegree.set(edge.to, (inDegree.get(edge.to) ?? 0) + 1);
  }

  const queue: string[] = [];
  for (const [id, deg] of inDegree) {
    if (deg === 0) queue.push(id);
  }
  queue.sort();  // 确定性拓扑序（RES.10 §二.5）

  const visited: string[] = [];
  while (queue.length > 0) {
    const current = queue.shift()!;
    visited.push(current);
    for (const next of adjacency.get(current) ?? []) {
      const deg = inDegree.get(next)! - 1;
      inDegree.set(next, deg);
      if (deg === 0) {
        queue.push(next);
        queue.sort();
      }
    }
  }

  if (visited.length !== nodes.length) {
    const cycleNodes = nodes
      .map((n) => n.id)
      .filter((id) => !visited.includes(id));
    return { hasCycle: true, cycleNodes };
  }
  return { hasCycle: false, cycleNodes: [] };
}
```

```typescript
export interface MergeResult<T> {
  success: boolean;
  state?: T;
  conflicts?: Array<{ field: string; prev: unknown; patch: unknown }>;
}

/** 可合并字段（@mergeable） */
const MERGEABLE_FIELDS = new Set(['messages', 'artifacts', 'retry_count']);

/** 合并策略 */
type MergeStrategy = (prev: unknown, patch: unknown) => unknown;

const STRATEGIES: Record<string, MergeStrategy> = {
  messages: (prev, patch) =>
    [...(prev as unknown[] ?? []), ...(patch as unknown[] ?? [])],
  artifacts: (prev, patch) =>
    ({ ...(prev as object ?? {}), ...(patch as object ?? {}) }),
  retry_count: (prev, patch) =>
    (prev as number ?? 0) + (patch as number ?? 0),
};

export function mergeState<T extends Record<string, unknown>>(
  prev: T,
  patch: Partial<T>,
): MergeResult<T> {
  const conflicts: MergeResult<T>['conflicts'] = [];
  const result = { ...prev };

  for (const [key, patchValue] of Object.entries(patch)) {
    const prevValue = prev[key];

    if (MERGEABLE_FIELDS.has(key)) {
      // 可合并字段：用策略合并
      const strategy = STRATEGIES[key];
      result[key as keyof T] = strategy(prevValue, patchValue) as T[keyof T];
    } else if (prevValue === undefined) {
      // 首次写入：直接赋值
      result[key as keyof T] = patchValue as T[keyof T];
    } else if (prevValue !== patchValue) {
      // 冲突：reject-on-conflict
      conflicts.push({ field: key, prev: prevValue, patch: patchValue });
    }
    // 值相同时：无操作
  }

  if (conflicts.length > 0) {
    return { success: false, conflicts };
  }
  return { success: true, state: result };
}
```

```typescript
/** 条件表达式求值（轻量自研，不引入完整 DSL） */
export function evaluateCondition(
  expr: string,
  state: Record<string, unknown>,
): boolean {
  // ① 字段替换：state.xxx → 实际值
  const replaced = expr.replace(/state\.(\w+)/g, (_, field) => {
    const value = state[field];
    return JSON.stringify(value);
  });

  // ② 白名单校验：只允许 === !== > < >= <= && || ! ( ) 和字面量
  if (!/^[\s\d"'.\-+*/<>=!&|()truefalsenull,]*$/.test(replaced)) {
    throw new ConditionEvalError(`条件表达式包含非法字符: ${expr}`);
  }

  // ③ 用 Function 求值（受限环境）
  try {
    return Boolean(new Function(`"use strict"; return (${replaced});`)());
  } catch (error) {
    throw new ConditionEvalError(`条件表达式求值失败: ${expr}`, error as Error);
  }
}

export class ConditionEvalError extends Error {
  constructor(message: string, public readonly cause?: Error) {
    super(message);
    this.name = 'ConditionEvalError';
  }
}

/** 循环状态 */
export interface LoopState {
  retry_count: number;
  max_iterations: number;
}

export function shouldRetry(state: LoopState): boolean {
  return state.retry_count < state.max_iterations;
}

export function shouldEscalate(state: LoopState): boolean {
  return state.retry_count >= state.max_iterations;
}

/**
 * 根据当前节点和边，决定下一节点
 *
 * RES.10 §一.1：条件边优先于静态边；`__END__` 哨兵 + 无出边即终止；
 * 每节点单出边；条件边返回旧节点=loop。
 */
export function resolveNextNode(
  current: string,
  edges: GraphDefinitionSpec['edges'],
  state: Record<string, unknown>,
): string | string[] | '__END__' {
  const outgoing = edges.filter((e) => e.from === current);

  if (outgoing.length === 0) return '__END__';

  // RES.10 §一.1：条件边优先于静态边
  const conditionalEdges = outgoing.filter((e) => e.type === 'cond' || e.type === 'loop');
  const staticEdges = outgoing.filter((e) => e.type === 'seq');

  // 条件边优先
  for (const edge of conditionalEdges) {
    if (edge.type === 'cond' && edge.when) {
      if (evaluateCondition(edge.when, state)) {
        return edge.to;
      }
    } else if (edge.type === 'loop') {
      const loopState = state as unknown as LoopState;
      if (shouldRetry(loopState)) {
        return edge.to;
      } else if (shouldEscalate(loopState)) {
        // 找审批节点
        const approval = edges.find(
          (e) => e.from === current && e.to.includes('approval'),
        );
        return approval?.to ?? '__END__';
      }
    }
  }

  // 静态边
  if (staticEdges.length > 0) {
    return staticEdges[0].to;
  }

  return '__END__';
}
```

```typescript
  run(initialState: T, options: RunOptions<T>): Promise<GraphExecutionResult<T>>;
}

export interface SubagentNodeOptions {
  provider: string;
  promptTemplate?: string;
  outputSchema?: unknown;
}

export function createStateGraph<T extends Record<string, unknown>>(
  ctx: Context,
  maxIterations = 25,
): StateGraph<T> {
  const nodes = new Map<string, NodeHandler<T>>();
  const edges: Array<{ from: string; to: string; type: string; when?: string; maxIter?: number }> = [];
  const approvalGates = new Map<string, { toolName: string; reason?: string }>();
  let entryPoint: string | null = null;

  const concurrency = createConcurrencyCounter(ctx, 8);

  return {
    addNode(name, handler) {
      if (name === '__END__') throw new Error('__END__ 是保留哨兵');
      if (nodes.has(name)) throw new Error(`节点已存在: ${name}`);
      nodes.set(name, handler);
      if (!entryPoint) entryPoint = name;
      return this;
    },

    addEdge(from, to) {
      edges.push({ from, to, type: 'seq' });
      return this;
    },

    addConditionalEdge(from, condition, maxIter) {
      // 条件边：condition 是函数，这里转为声明式
      edges.push({ from, to: '__CONDITION__', type: 'cond', maxIter });
      // 实际执行时调用 condition 函数（需要额外存储函数引用）
      return this;
    },

    addApprovalGate(name, options) {
      approvalGates.set(name, options);
      // RES.10 §一.5：审批门可以无 handler（纯门，空增量）
      if (!nodes.has(name)) {
        nodes.set(name, async () => ({} as Partial<T>));
      }
      return this;
    },

    async run(initialState, options) {
      if (!entryPoint) throw new Error('图无入口节点');

      const graphId = `graph-${Date.now()}-${Math.random().toString(36).slice(2, 8)}`;
      const trajectory: TrajectoryEvent[] = [];
      let state = initialState;
      let current = entryPoint;
      let iteration = options.initialIteration ?? 0;

      const emit = (event: TrajectoryEvent) => {
        trajectory.push(event);
        ctx.emit(event.type, event);
      };

      emit({ type: 'graph/start', graphId, timestamp: Date.now() });

      while (current !== '__END__') {
        // RES.10 §一.3：计数在"进入节点前"，第 N 次仍执行完，第 N+1 次抛错
        if (++iteration > maxIterations) {
          const err = new Error(`迭代次数超过上限（${maxIterations}），疑似死循环，已终止。`);
          emit({ type: 'graph/error', graphId, timestamp: Date.now(), data: { error: err.message } });
          return { graphId, success: false, finalState: state, trajectory, iterations: iteration, error: err };
        }

        // RES.5 §四：全局并发闸
        const acquired = await concurrency.acquire();
        if (!acquired) {
          const err = new Error(`并发闸拒绝激活节点: ${current}`);
          emit({ type: 'graph/node-error', graphId, node: current, timestamp: Date.now(), data: { error: err.message } });
          return { graphId, success: false, finalState: state, trajectory, iterations: iteration, error: err };
        }

        try {
          const handler = nodes.get(current);
          if (!handler) throw new Error(`节点不存在: ${current}`);

          // RES.10 §一.5：审批门执行前先请求审批
          const gate = approvalGates.get(current);
          if (gate && options.agent) {
            const outcome = await ctx.approval.request({
              agent: options.agent,
              toolName: gate.toolName,
              reason: gate.reason,
              signal: options.signal,
            });
            if (outcome !== 'allowed-once') {
              throw new Error(`审批门 "${current}" 未通过（${outcome}）`);
            }
          }

          const nodeCtx: GraphNodeContext<T> = {
            ctx,
            graphId,
            graphVersion: '1.0',  // 由外部注入
            emit,
            logger: ctx.logger,
            checkpoint: options.checkpoint,
            iteration,
            agent: options.agent,
          };

          emit({ type: 'graph/node-start', graphId, node: current, timestamp: Date.now() });

          const startTime = Date.now();
          const patch = await handler(state, nodeCtx, options.signal);

          // RES.10 §一.2：浅合并（本项目扩展为 mergeState 冲突检测）
          const mergeResult = mergeState(state, patch);
          if (!mergeResult.success) {
            emit({
              type: 'graph/node-error', graphId, node: current, timestamp: Date.now(),
              data: { conflicts: mergeResult.conflicts },
            });
            return {
              graphId, success: false, finalState: state,
              trajectory, iterations: iteration,
              error: new Error(`状态合并冲突: ${JSON.stringify(mergeResult.conflicts)}`),
            };
          }
          state = mergeResult.state!;

          emit({
            type: 'graph/node-end', graphId, node: current, timestamp: Date.now(),
            durationMs: Date.now() - startTime,
          });

          // RES.10 §一.4：checkpoint 在"补丁合并后、跳转前"调用
          await options.checkpoint({
            graphId,
            graphVersion: '1.0',
            graphSchemaHash: '',
            node: current,
            state,
            iteration,
            timestamp: Date.now(),
          });
          emit({ type: 'graph/checkpoint-written', graphId, node: current, timestamp: Date.now() });

          // RES.10 §一.1：解析下一节点
          const next = resolveNextNode(current, edges as never, state);
          if (next === '__END__') break;
          if (Array.isArray(next)) {
            current = next[0];  // MVP-2 不支持并行
          } else {
            current = next;
          }
        } catch (error) {
          emit({
            type: 'graph/node-error', graphId, node: current, timestamp: Date.now(),
            data: { error: (error as Error).message },
          });
          return {
            graphId, success: false, finalState: state,
            trajectory, iterations: iteration, error: error as Error,
          };
        } finally {
          // RES.5 §四：release 必须在 finally（防止节点失败死锁）
          concurrency.release();
        }
      }

      emit({ type: 'graph/end', graphId, timestamp: Date.now() });
      return { graphId, success: true, finalState: state, trajectory, iterations: iteration };
    },
  };
}
```

```typescript
import type { GraphNodeSpec } from '../l2-engine/types.js';

export interface L1CheckResult {
  passed: boolean;
  signal: 'green' | 'yellow' | 'red';

/** 节点 ID 正则（与 T2 Schema 一致） */
const NODE_ID_PATTERN = /^[a-z][a-z0-9_-]*$/;

export function checkL1(
  node: GraphNodeSpec,
  state: Record<string, unknown>,
): L1CheckResult {
  const findings: L1CheckResult['findings'] = [];

  // ① 命名规范
  if (!NODE_ID_PATTERN.test(node.id)) {
    findings.push({
      check: 'naming',
      message: `节点 ID 不符合命名规范: ${node.id}`,
    });
  }

  // ② 权限：role 节点必须有 roleRef
  if (node.nodeType === 'role' && !node.roleRef) {
    findings.push({
      check: 'permission',
      message: `role 节点必须有 roleRef: ${node.id}`,
    });
  }

  // ③ 状态：retry_count 不能为负
  if (typeof state.retry_count === 'number' && state.retry_count < 0) {
    findings.push({
      check: 'state',
      message: `retry_count 不能为负: ${state.retry_count}`,
    });
  }

  if (findings.length === 0) {
    return { passed: true, signal: 'green', findings: [] };
  }
  return { passed: false, signal: 'yellow', findings };
}
```

```typescript
    // ① 写入 checkpoint（graphVersion="1.0.0"）
    // ② 用不同版本恢复（graphVersion="2.0.0"）
    // ③ 验证返回 { error: 'VERSION_MISMATCH', storedVersion, currentVersion }
  });

```

**验收标准**：
- [ ] 版本相同 → 恢复 state
- [ ] 版本不同 → 返回 `VERSION_MISMATCH`（不尝试迁移）
- [ ] 无 checkpoint → 返回 `null`

## 十、总结

**MVP-2 是质变点**：从"一堆 skill"到"编排工具"的跨越发生在这里。

**基于 Phase F 实测的设计基线**：
- **API 名确认**：`sendMessage`（非 `followup`/`reportFrom`），`ctx.llm.stream`（非 `complete`）
- **模型路由可信**：`agentRouteDefaults` 生效（FIX.4）
- **并发闸必须自建**：官方无内置并发闸（RES.5）
- **资源生命周期强制**：7 项检查清单（RES.4）
- **引擎设计有参考**：`dsh-state-graph` 8 项可直接采用（RES.10）
- **图版本迁移有依据**：AgentGit 快照 + CVC 内容寻址（RES.8）
- **Token 采集点在节点层**：读 session `data.usage`（RES.1）

**核心设计原则**：
1. **图范式代替脚本**：`GraphDefinitionSpec` + `StateGraph<T>`
2. **纯函数增量补丁**：节点返回 `Partial<State>`，引擎原子合并
3. **冲突显式暴露**：`reject-on-conflict`
4. **checkpoint 是契约**：必需参数 + 版本感知
5. **零 Token 可测**：路由/条件边/熔断是纯函数
6. **严格 Cordis 生命周期**：7 项检查清单
7. **失败即暴露**：fail-fast、不吞错

**关键里程碑**：
- 第 2 周末：T8 引擎骨架完成
- 第 3 周末：T14 测试矩阵全绿（质变点接近）
- 第 4 周末：MVP-2 门禁 7 项通过，**质变点达成**

**下一步**：Harness 从 T1 开始执行，每个任务完成后跑 T13 增量检查，遇到阻塞时按 §8.3 处理。
