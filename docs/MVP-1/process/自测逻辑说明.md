# 自测逻辑与测试矩阵（MVP-1）

> 版本：v1（2026-09-22）｜目标读者：开发者/QA
> 说明：MVP-1 的测试分两层——**确定性单测**（零 LLM，快速）与**隔离环境验证**
> （真实 DSH 运行时，mock/真实 LLM）。全部在 `test-env` 隔离执行，不污染主环境。

## 一、确定性单测（vitest，零 LLM，秒级）

### 1.1 运行方式

```powershell
cd 3pluginCode
pnpm test          # 全部单测
pnpm typecheck     # tsc --noEmit（host + client）
```

### 1.2 测试矩阵（56 用例）

| 测试文件 | 覆盖 | 用例数 |
|---|---|---|
| `tests/shared/types.spec.ts` | RoleDefinitionSchema：合法/非法/边界/枚举/observers；错误类 | 8 |
| `tests/shared/logger.spec.ts` | 结构化输出/error 走 stderr/trace 贯穿/脱敏工具 | 7 |
| `tests/l3-roles/role-schema.spec.ts` | parseRoleYaml：合法/缺失字段/非法枚举/语法错误/非对象 | 6 |
| `tests/l3-roles/role-loader.spec.ts` | 字段映射/包装 provider 注入/路径逃逸/skill 错误/批量编译/脱敏 | 14 |
| `tests/l2-engine/chain-runner.spec.ts` | 串行按序/产物落盘/摘要传递/fail-fast/非 completed 落盘 | 6 |
| `tests/lifecycle/cordis-effect.spec.ts` | ctx.effect 注册注销/LIFO/幂等/插件卸载清理/异步 await | 5 |

### 1.3 关键断言点

- **模型完整对象**：`agentOptions` 必须是完整 `{ provider, model }`（🐛 #4311/#4313 规避）
- **记忆隔离**：`inheritsParentContext` = `memory_scope === 'shared'`（private → false）
- **路径逃逸**：`../../secret.txt` 抛 `RoleLoadError`（不允许逃逸 skillsDir）
- **toolFilter 注入**：`start()` 注入 `toolFilter: { allow: [...tools] }`
- **脱敏**：日志不含 persona 全文（只长度 + 指纹）

## 二、隔离环境验证（真实 DSH 运行时）

### 2.1 验证层次（对应 R5 测试分层）

| 层 | 内容 | 方式 | 用时 |
|---|---|---|---|
| L2 服务级 | 角色注册到 ctx.subagents | headless boot 日志 | 秒级 |
| L3 集成 | 单链串行执行 + 产物落盘 | headless 端到端（mock LLM） | ~1 分钟 |
| L3 集成 | 记忆隔离 / toolFilter 运行时证据 | session 事件扫描脚本 | 秒级 |
| L4 端到端 | 真实 LLM 全链（可选） | headless 端到端（真实 key） | 15-40 分钟 |

### 2.2 验证脚本清单（`test-env/`）

| 脚本 | 用途 |
|---|---|
| `verify-roles.mjs` | 编译 roles/ 目录全部角色（6 个），打印脱敏摘要 |
| `scan-session-events.mjs` | 扫描 session 事件类型（subagent/catalog 等节点证据） |

| `check-tool-pairing.mjs` | 工具 call/result 配对（找 hang） |
| `probe-web.mjs` | 隔离 web API 探测（cookie 认证） |
| `fix-pnpm-links.mjs` | 修复 pnpm 12 Windows 链接失效 |
| `check-installed.mjs` / `check-bundles.mjs` | 校验安装后插件结构与 bundle 层 |

## 四、门禁复验流程（一键顺序）

```powershell
# 前置：mock LLM server 运行（见隔离环境启动手册 §2.1）
# 1. 确定性单测
cd 3pluginCode && pnpm test && pnpm typecheck

# 2. 打包安装
pnpm build && pnpm pack --pack-destination ./dist
$env:DSH_HOME = '<项目>\3pluginCode\test-env\dsh-home'
$dshBin = "$env:USERPROFILE\.dsh\profiles\node_modules\@deepseek-ai\dsh\lib\bin.js"
node $dshBin plugin --profile weave-headless remove dsh-agent-weave
node $dshBin plugin --profile weave-headless add "<项目>\3pluginCode\dist\dsh-agent-weave-0.1.0.tgz"

# 3. 端到端（门禁 1/2/3）
$env:MOCK_LLM_API_KEY = 'mock-key'
node $dshBin --profile weave-headless "请调用 weave_run_chain 工具，user_input 为 '做一个计算器'"

# 4. 门禁 4（web chat 节点，人工）
node $dshBin --profile weave-test --no-open --port 0
# 打开日志中的 URL，发消息观察子代理节点树

# 5. 验收
#   - productions/<角色ID>/ 6 个文件存在
#   - 日志全部 stop_reason=completed
#   - session 扫描见 6 个 subagent/catalog（节点证据）
```

## 五、测试数据保留策略

- `test-env/` 默认**不清理**，跨会话保留（D-10 规则）
- 真实 LLM 产物 `productions/` 保留（含 R1/R2/R4 已生成的真实文档）
- mock/真实 settings 均有备份（`settings.yaml.mock.bak`）
- 用户确认后才允许清理；禁止自动删除
