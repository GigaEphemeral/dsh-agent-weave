## 三、发现与处置

### ⚠️ 发现 1：`chain-runner.ts` heartbeat setInterval（MVP-1 遗留）

- 位置：`src/l2-engine/chain-runner.ts` L200
- 现状：`setInterval` 每 10s 写心跳，L219 `clearInterval(heartbeat)` 清理
- 风险：未用 `ctx.effect()`，若热重载/异常路径可能泄漏；但该模块是**一次性 CLI 调用**（weave_run_chain），非常驻插件服务
- **处置**：MVP-1 遗留，属 MVP-3「消息总线/中止传播」改造范围；已在 T17 报告登记 TODO
- **不阻塞 MVP-2**：MVP-2 引擎（state-graph）无任何裸定时器

### ⚠️ 发现 2：`graph-visual-commands.ts` mock 延迟 setTimeout

- 位置：`src/cli/graph-visual-commands.ts` L55 `await new Promise((r) => setTimeout(r, MOCK_NODE_DELAY_MS))`
- 性质：**一次性**延迟（模拟子代理耗时），非循环定时器；mock 验收场景专用
- 处置：无需 effect（执行完即释放）；MVP-3 接入真实 subagent 后移除
- 不阻塞

### ✅ 发现 3：`observer-l1.ts` 含 `ctx.llm` 字样

- 位置：JSDoc 注释「不调用 ctx.llm」
- 性质：**注释**，非实际调用（单测已断言无 `ctx.llm.` 调用）
- 处置：无需修改
