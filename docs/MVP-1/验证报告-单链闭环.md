## 四、关键技术验证点（D-001 修正落地）

1. **SubagentProvider 官方契约**：`capabilities` 为布尔标志；persona/toolFilter/agentOptions 属 start 请求；角色以「包装 provider」存在（`start()` 注入角色字段 → 委托 spawn）。
2. **workflowEngine 限制**：`agent()` 的 `provider` 是 LLM 路由覆盖，非子代理 provider 选择 → MVP-1 用自写编排（`chain-runner`）+ `weave_run_chain` 工具。
3. **模型路由**：角色 `model.provider=huoshan-186`（llm-pi-ai），与主环境 llm-pi-ai 配置一致；隔离环境指向 mock server 验证机制。
4. **路径解析**：roles/skills 基于插件包根（`import.meta.url`）解析，不依赖 `process.cwd()`。
