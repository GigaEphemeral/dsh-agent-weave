# 问题一：看板无法实时显示图执行进展 · 完整方案

> 单独拆出，为后续子代理问题留出空间。

---

## 一、现象

### 用户视角

```
1. 用户输入："调用 weave 插件执行开发任务"
2. 主 agent 开始调工具，chat 里 todo 滚动
3. 用户点 "Weave 看板" → 切到看板
4. 看板显示：
   ┌─────────────────────────────────┐
   │ graphId（可留空=最近运行）       │
   │ [        ] [暂停] [恢复] [终止]  │
   │ （无图数据，请先运行 weave_run_graph）
   │ Token 消耗（总 0）
   │ 审批待办（0）
   │ 观察者信号（0）
   │ Agent 消息流（零 token）
   │ 运行历史（暂无）
   └─────────────────────────────────┘
5. 图实际在跑，但看板一片空白
6. 几十分钟后，主 agent 返回 → chat 显示 "图 ID: graph-xxx"
7. 用户把 graphId 输入看板 → 图早跑完了，实时过程错过
```

### 关键旁证

- Shell 里 `[weave-addsubagent]` 日志**持续输出**（图在跑）
- 浏览器 Network**没有** `/api/weave/graph/<id>/status` 和 `/stream` 请求
- 从 shell 抓 graphId 手动输入：**有时命中、有时 404**

---

## 二、根因分析（四层）

### 根因 1：两个 graphId 不一致（前置硬 bug）

| 位置 | 使用的 graphId | 代码 |
|---|---|---|
| `runGraphRealTool` 的 bus/registry/返回值 | **A**（4 字符后缀） | `graph-${Date.now()}-${rand(4)}` |
| `graph.run` 内部 emit 的事件 | **B**（6 字符后缀） | `graph-${Date.now()}-${rand(6)}` |

**两处各自生成**，从没对齐。然后 `event-bus.handle()` 收到 `graph/start` 时把内部状态覆盖成 B：

```typescript
case 'graph/start':
  graphId = event.graphId   // ← 被覆盖成 B
```

**结果**：
- `/api/weave/graph/<B>/status` → 200（bus 内部是 B）
- `/api/weave/graph/<A>/status` → **404**（routes 严格比对）
- 前端拿返回值 A 去查 → 404 → 看板空白

**"有时命中、有时 404" 就是这么来的。**

### 根因 2：`weave_run_graph` 是同步工具调用

```typescript
const result = await graph.run(initialState, { ... })  // ← 阻塞几十分钟
return { ok: result.success, graphId, ... }             // ← 此时才返回 graphId
```

**时间线**：

```
T+0s     主 agent 调 weave_run_graph
T+0.5s   工具内部生成 graphId，开始 await graph.run(...)
T+1s     主 agent 卡住
T+30s    用户打开看板 → graphId 空 → 空白
T+40min  图跑完，工具返回 graphId
T+40min  主 agent 回复用户："图已完成"
```

**用户拿到 graphId 时，实时过程已经错过。**

### 根因 3：前端 graphId 为空时不请求

```typescript
// useGraphStream.ts
useEffect(() => {
  if (!graphId) {       // ← null 时直接 return
    setSnap(null); setSpec(null)
    return              // 不发任何请求
  }
  fetch(`/api/weave/graph/${graphId}/status`)...
}, [graphId])
```

**看板提示 "graphId（可留空=最近运行）" 是误导的**——留空什么也不查。

### 根因 4：没有"新图启动"的全局广播通道

- Host 端 `event-bridge` 只订阅**具体 graphId 的 bus**
- 前端 `useGraphStream(graphId)` 只订阅**具体 graphId 的 SSE**
- **没有"全局流"**——前端无法感知"有新图启动了"

## 三、修复方案（6 步）

### 步骤 0：统一 graphId（前置，必做）

**`src/l2-engine/types.ts`** 加字段：

```typescript
export interface RunOptions<T> {
  checkpoint: CheckpointCallback<T>
  graphVersion: string
  graphSchemaHash: string
  agent?: Agent
  signal?: AbortSignal
  initialIteration?: number
  initialLoopUsage?: Record<string, number>
  approvalPolicy?: { ... }
  /** ★ 新增：外部指定的 graphId */
  graphId?: string
}
```

**`src/l2-engine/state-graph.ts`** 的 `run` 改为从 `options` 读：

```typescript
async run(initialState, options) {
  // ...
  // ★ 从 options 读，缺省才自己生成
  const graphId = options.graphId ?? `graph-${Date.now()}-${Math.random().toString(36).slice(2, 8)}`
  // ... 后续不变
}
```

**`src/cli/graph-run-commands.ts`** 传入：

```typescript
const graphId = `graph-${Date.now()}-${Math.random().toString(36).slice(2, 6)}`
const bus = setGlobalBus(graphId)
// ...
const result = await graph.run(initialState, {
  checkpoint, graphVersion, graphSchemaHash, agent: parent,
  graphId,   // ★ 传入
})
```

**效果**：返回值 A = 事件流 B = bus 内部 A。`/status` 不再 404。

### 步骤 1：`weave_run_graph` 改异步，秒返回 graphId

**`src/cli/graph-run-commands.ts`**：

```typescript
// ① 立即广播 graph/start（不等图执行）
bus.handle({ type: 'graph/start', graphId, timestamp: Date.now() })

// ② 图在后台跑（不 await）
graph.run(initialState, { checkpoint, graphVersion, graphSchemaHash, agent: parent, graphId })
  .then((result) => ctx.logger.info('weave', '图执行结束', { graphId, success: result.success }))
  .catch((err) => ctx.logger.error('weave', '图执行失败', err))

// ③ 秒返回
return {
  ok: true,
  graphId,
  artifactsRoot: root,
  tracesDir: join(root, 'traces'),
  status: 'started' as const,
  message: `图已启动（异步执行中），graphId=${graphId}`,
}
```

**工具 description 同步改**：

```
'启动图执行（**异步**）：读 YAML → 校验 → 后台运行真实子代理 → **立即返回 graphId**。' +
'图在后台跑，前端通过 graphId 订阅实时进展。' +
'返回值 status="started" 表示图已启动未完成。'
```

### 步骤 2：Host 端加全局 SSE 端点

**`src/l4-visual/host/sse-broker.ts`**：`broadcast` 支持 `graphId = '*'`：

```typescript
broadcast(graphId: string, event: WsEvent & { seq?: number }): void {
  const line = `data: ${JSON.stringify(event)}\n\n`
  for (const [id, sub] of subs) {
    // ★ 匹配具体 graphId 或全局订阅
    if (sub.graphId !== graphId && sub.graphId !== '*') continue
    try {
      sub.res.write(line)
      if (event.seq !== undefined) sub.lastSeq = event.seq
    } catch { subs.delete(id) }
  }
}
```

**`src/l4-visual/host/routes.ts`** 加全局端点：

```typescript
// GET /api/weave/stream —— 全局事件流
if (rest === '/stream') {
  if (method !== 'GET') { json(res, 405, { error: 'method not allowed' }); return }
  const lastEventId = req.headers?.['last-event-id']
  const raw = Array.isArray(lastEventId) ? lastEventId[0] : lastEventId
  const subId = broker.subscribe('*', res as never, raw)
  req.on?.('close', () => broker.unsubscribe(subId))
  return
}
```

### 步骤 3：Client 端订阅全局 SSE

**`src/client/index.tsx`**：

```tsx
export function apply(ctx: Context): void {
  // ... 现有 D1/D3 注册

  // ★ 新增：订阅全局 SSE
  try {
    const es = new EventSource('/api/weave/stream')
    es.onmessage = (msg) => {
      try {
        const evt = JSON.parse(msg.data)
        if (evt.event_type !== 'graph-start') return
        const graphId = evt.trace_id
        if (!graphId) return
        console.log('[weave-client] 捕获 graph-start，graphId:', graphId)

        // 触发自定义事件
        window.dispatchEvent(new CustomEvent('weave:graph-started', { detail: { graphId } }))

        // 尝试自动切 tab（DSH API 待 PR-M4.5 探测）
        try {
          const slots = (ctx as any).slots
          if (slots?.activate) slots.activate('conversation.view', 'weave-dashboard')
        } catch {
          console.log('[weave-client] 无法自动切 tab，请手动点"Weave 看板"')
        }
      } catch { /* 忽略 */ }
    }
    es.onerror = () => { /* EventSource 自动重连 */ }
    ctx.effect(() => () => es.close())
  } catch (err) {
    console.error('[weave-client] 订阅全局 SSE 失败', err)
  }
}
```

### 步骤 4：`WeaveDashboardView` 自动绑定 graphId

**`src/client/dashboard/WeaveDashboardView.tsx`**：

```tsx
export function WeaveDashboardView() {
  const [graphId, setGraphId] = useState<string | null>(null)
  // ...

  // ★ 监听图启动事件
  useEffect(() => {
    function onGraphStarted(e: Event) {
      const { graphId: newId } = (e as CustomEvent<{ graphId: string }>).detail
      console.log('[weave-client] WeaveDashboardView 自动绑定:', newId)
      setGraphId(newId)
    }
    window.addEventListener('weave:graph-started', onGraphStarted)
    return () => window.removeEventListener('weave:graph-started', onGraphStarted)
  }, [])

  // ★ 兜底：拉当前活跃图
  useEffect(() => {
    if (graphId) return
    fetch('/api/weave/graphs/active')
      .then((r) => (r.ok ? r.json() : null))
      .then((d) => { if (d?.graphId) setGraphId(d.graphId) })
      .catch(() => {})
  }, [graphId])

  // ... 其余渲染
}
```

## 七、一句话

**看板无法实时显示的四层根因：① `runGraphRealTool` 和 `graph.run` 各生成一个 graphId，前端拿返回值 404；② 工具同步调用，graphId 跑完才返回；③ 前端 graphId 空时不请求；④ 无"新图启动"全局广播。修法六步：统一 graphId → 工具异步化 → 全局 SSE → Client 订阅 → 看板自动绑定 → 兜底 active 端点。~1.9d，除"自动切 tab"外无外部依赖。**
