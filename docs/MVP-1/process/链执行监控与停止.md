# 链执行监控与停止（用户自助操作卡）

> 版本：v1（2026-09-22）｜用途：**你自己**实时看 AI 在干什么、随时叫停，无需外部监看
> 背景：编排在 DSH 进程内跑，进程 stdout 你看不到 → 现把执行细节落盘为用户可读日志

## 一、实时看日志（AI 在干什么）

```powershell
# 实时跟踪（Ctrl+C 退出查看，不影响链执行）
Get-Content 'D:\dsharness\agentDev\softwareEngnieering\productions\chain.log' -Wait -Tail 30
```

### 日志内容（每行一条 JSON）

| 事件 | 含义 | 关键字段 |
|---|---|---|
| `链开始` | 链启动 | `total_steps`、`roles`、`log_file`、`stop_flag` |
| `阶段开始：<阶段名>` | 某角色开始工作 | `step`（第几阶段/共几）、`role_id`、`prompt_len` |
| `心跳：<阶段名> 仍在执行` | **每 10 秒一次**（证明没卡死） | `elapsed_s`（已耗时秒数） |
| `阶段完成：<阶段名>` | 某角色完成 | `stop_reason`、`elapsed_s`、`output_len`、`artifact` |
| `检测到 STOP 标志，链中止` | 你叫停了 | `stopped_before`、`completed_steps` |
| `链结束` / `链已中止` | 链终止 | `completed_steps`、`total_elapsed_s`、`artifacts` |

### 怎么判断状态

- 看到**心跳持续更新** → AI 正在干活（慢模型可能单阶段几分钟，属正常）
- 心跳里 `elapsed_s` 一直涨但阶段不推进 → 该阶段耗时较长（可继续等或叫停）
- 长时间**没有新行**（超过 ~15 秒无心跳） → 可能异常，可叫停后排查

## 二、随时叫停

```powershell
# 停止：创建 STOP 标志（链会在【当前阶段完成后】中止，不启动后续阶段）
New-Item 'D:\dsharness\agentDev\softwareEngnieering\productions\STOP' -Force
```

> 注意：**阶段边界生效**——正在执行的角色会跑完当前一轮，然后链停止。
> 如需立即中断整个进程，用 web UI 的停止按钮（或告诉我）。

```powershell
# 恢复（清掉标志，下次执行不再中止）
Remove-Item 'D:\dsharness\agentDev\softwareEngnieering\productions\STOP' -Force
```
