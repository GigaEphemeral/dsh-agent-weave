## 二、怎么验证（三步）

### 第 1 步：发一条需求

在 chat 输入框发送（**建议先复制这句话，明确要求调用工具**）：

```
调用 weave_run_chain 工具，user_input 为：做一个待办事项命令行工具
```

> 也可以只写需求（如「做一个待办事项 CLI 工具」），主 Agent 通常会自动调用该工具。
> 建议任务**简单**：真实 LLM 每阶段需 3-15 分钟。

### 第 2 步：观察「workflow 节点」（门禁 4 核心）

预期在 chat 中依次看到：

| 观察点 | 说明 |
|---|---|
| ① 工具调用卡片 | 主 Agent 调用 `weave_run_chain`（参数 `user_input`） |
| ② 子代理节点树 | R1→R2→R4→R6→R7→R8 依次出现，状态点 `running`（进行中）→ `done` |
| ③ 节点标签 | 显示中文阶段名 + 角色 ID，如「需求分析（R1-requirement）」 |
| ④ 点击节点 | 可进入该子代理的独立会话（验证**记忆隔离**：每个角色独立 Session） |

> 节点树数据源：`subagent/catalog` 事件（已在 session 日志中验证）。

- 角色会真实调用工具（read/glob/pwsh），可在子代理会话中看到
- 若某阶段较久，属正常（模型在生成长文档）
