# MVP-4 事件流契约

> 版本：v1（2026-09-24）｜对齐 OTEL GenAI 语义 + 业务事件类型。

## 一、事件链路

```
引擎 emit（TrajectoryEvent）
  → eventSink（P4.0.1）→ 全局共享 bus（shared-bus.ts）
  → event-bridge（P4.B.2）→ trajectoryToWsEvent（event-schema.ts）
  → SSE broker（P4.A.3）→ 浏览器 EventSource
```

旁路（不经过引擎 emit）：
- `agent-message`：message-bus.send 后追加 RunLedger（P4.B.11，零 token）
- `approval-request/decided`：approval-service create/resolve 直接广播（P4.B.3）
- `observer-signal`：引擎 node-end 后触发观察器写 ledger + eventSink（P4.B.7）

## 二、WsEvent 结构（SSE data 载荷）

```typescript
{
  trace_id: string,                    // = graphId
  span_id?: string,                    // = node
  'gen_ai.agent.name'?: string,        // = roleMap[node]
  'gen_ai.operation.name'?: 'invoke_agent' | 'node_start' | 'node_end' | 'observer_signal',
  'gen_ai.usage.input_tokens'?: number,
  'gen_ai.usage.output_tokens'?: number,
  'gen_ai.usage.cache_read_tokens'?: number,
  event_type: 'graph-start' | 'node-start' | 'node-end' | 'node-error'
            | 'loop-iteration' | 'checkpoint-written'
            | 'observer-signal' | 'agent-message'
            | 'approval-request' | 'approval-decided' | 'graph-end',
  node?: string,
  timestamp: number,
  data: Record<string, unknown>,
}
```

## 三、event_type → UI 行为

| event_type | 触发源 | UI 行为 |
|---|---|---|
| graph-start | 引擎 | 初始化快照 |
| node-start | 引擎 | 节点 → running |
| node-end | 引擎 | 节点 → completed；tokenUsed 累加 |
| node-error | 引擎 | 节点 → failed |
| loop-iteration | 引擎 | 更新 iteration |
| checkpoint-written | 引擎 | （无 UI 直接变化） |
| observer-signal | 引擎观察器 | SignalPanel 追加 + 热力图 |
| agent-message | message-bus | MessageFlowPanel 时间线 |
| approval-request | approval-service | ApprovalPanel 待办 + 倒计时 |
| approval-decided | approval-service | ApprovalPanel 标记已决 |
| graph-end | 引擎 | 快照 status → completed/paused/waiting |

## 四、断线重连

- EventSource 自动重连（浏览器内置）；服务端心跳注释行 `: connected <id>`。
- `last-event-id` header 透传（broker 记录 lastSeq，MVP-4 未做重放，Phase B 门禁达标项）。

## 五、REST 端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/weave/graphs | 运行历史（traces/*.jsonl） |
| GET | /api/weave/graph/:id/status | 快照 |
| GET | /api/weave/graph/:id/spec | 图定义 + roleMap |
| GET | /api/weave/graph/:id/stream | SSE |
| GET | /api/weave/graph/:id/tokens | Token 分账 |
| GET | /api/weave/graph/:id/approvals | 审批列表 |
| GET | /api/weave/graph/:id/checkpoints | 恢复点 |
| GET | /api/weave/graph/:id/node/:nid/activity | 节点活动 |
| POST | /api/weave/graph/:id/pause\|resume\|stop | 图控制 |
| POST | /api/weave/approval/:aid/approve\|reject | 审批决议 |

鉴权：`x-weave-token` header = `WEAVE_API_TOKEN` env（未配置 env 时放行，本地单机）。

## 六、webServer 接入契约（预研确认）

- `ctx.get('webServer')` 鸭子类型（不可 inject，headless 会挂起）
- `register({ kind: 'exact'|'prefix', path, handler(req,res) })` 对象形式
- 路径参数手动解析（kind:'prefix' + split）
