# 问题 1：看板无法实时显示图执行进展

## 1.1 现象

- 图开始跑后，看板空白；图跑完才从 chat 里看到 graphId
- Host 端日志持续输出，但浏览器 Network 无 `/api/weave/graph/<id>/status` 和 `/stream` 请求
- 从 shell 抓 graphId 手动输入：**有时命中、有时 404**

## 1.2 根因（四层）

### 根因 1：两个 graphId 不一致（前置硬 bug）

`src/cli/graph-run-commands.ts`：

```typescript
const graphId = `graph-${Date.now()}-${Math.random().toString(36).slice(2, 6)}`  // A（4 字符）
const bus = setGlobalBus(graphId)
bus.handle({ type: 'graph/start', graphId, ... })
registerGraph(graphId, { spec, roleMap, artifactsRoot: root })  // registry 用 A

const result = await graph.run(initialState, { checkpoint, ... })  // 内部又生成 B（6 字符）
return { ok: result.success, graphId, ... }  // 返回 A
```

`src/l2-engine/state-graph.ts`：

```typescript
async run(initialState, options) {
  const graphId = `graph-${Date.now()}-${Math.random().toString(36).slice(2, 8)}`  // B（6 字符）
  const emit = (event) => {
    ctx.emit(event.type, event)
    eventSink?.(event)  // 事件里是 B
  }
  emit({ type: 'graph/start', graphId, ... })  // B
}
```

`event-bus.ts` 的 handle 用 `event.graphId` 覆盖内部状态 → bus 内部是 B。
`routes.ts` 严格比对 `snap.graphId === graphId` → 前端拿 A 查 404。

### 根因 2：`weave_run_graph` 同步阻塞

```typescript
const result = await graph.run(initialState, { ... })  // 阻塞几十分钟
return { ok: result.success, graphId, ... }  // 跑完才返回 graphId
```

### 根因 3：前端 graphId 为空时不请求

```typescript
useEffect(() => {
  if (!graphId) { setSnap(null); setSpec(null); return }  // null 时不查
  fetch(`/api/weave/graph/${graphId}/status`)...
}, [graphId])
```

### 根因 4：无"新图启动"全局广播

Host 端 `event-bridge` 只订阅具体 graphId 的 bus；无全局流供前端感知新图启动。

# 问题 2：子代理自动 spawn 下级

## 2.1 现象

R1 单节点 114K tok，内部 spawn 6 个子代理（列出目录、读文件、探测环境、写文件、清理）。整个图 token 消耗 5-10 倍。

## 2.2 根因（三层）

1. **引擎层**：`maxDepth` 被错赋为 `max_concurrent_children=8`（语义错位）
2. **工具层**：`subagent` / `list_subagent_models` 是**内置能力**，**不受 `toolFilter` 管**
3. **Prompt 层**：skill 未禁止"分派任务"

**关键发现**：`tools: [read]` 的角色依然能调 `subagent`——因为它是每个 agent 的基础能力，不走 toolFilter。

## 2.3 修复：能力声明机制

# 问题 3：子代理无法互动

## 3.1 现象

- 图的子代理（R1/R2/...）跑完即销毁，用户无法与它对话
- 但 R6 内部 spawn 的子代理可以交互

## 3.2 根因

`state-graph.ts` 的 `addSubagent` 用 `start()`（one-shot），非 `startContinuable()`（durable）。

```typescript
const run = await nodeCtx.ctx.subagents.start(options.provider, { ... })
const result = await run.result  // 跑完即销毁
```

## 3.3 修复

### 修复 1：`addSubagent` 改 continuable

**`src/l2-engine/state-graph.ts`**：

```typescript
addSubagent(name, options) {
  if (nodes.has(name)) throw new Error(`节点已存在: ${name}`)
  
  // 节点级持久化：node → childId
  const childIdByNode = new Map<string, string>()

  nodes.set(name, async (state, nodeCtx, signal) => {
    const agent = nodeCtx.agent
    if (!agent) throw new Error(`子代理节点 "${name}" 需要 RunOptions.agent`)

    const existingChildId = childIdByNode.get(name)
    let result

    if (!existingChildId) {
      // 首次激活：创建 durable child
      const run = await nodeCtx.ctx.subagents.startContinuable(options.provider, {
        prompt: [{ type: 'text', text: buildInitialPrompt(options, state) }],
        parent: agent as never,
        ...(signal ? { signal } : {}),
        label: `${name}（${options.provider}）`,
      })
      childIdByNode.set(name, run.id)
      result = await run.result
    } else {
      // 循环回退：sendMessage 追加反馈
      const feedback = buildFeedbackFromState(state, name)
      const run = await nodeCtx.ctx.subagents.sendMessage(
        agent as never,
        existingChildId,
        [{ type: 'text', text: feedback }],
        {},
      )
      result = await run.result
    }

    const text = result.output.map((b) => (b.type === 'text' ? b.text : '')).join('\n').trim()
    // ... 落盘 + patch
  })
}
```

### 修复 2：前端加"子代理对话面板"

**`src/client/dashboard/SubagentChat.tsx`**：

```tsx
export function SubagentChat({ graphId, nodeId }: { graphId: string; nodeId: string }) {
  const [messages, setMessages] = useState<Array<{ role: string; text: string; ts: number }>>([])
  const [input, setInput] = useState('')
  const [running, setRunning] = useState(false)

  useEffect(() => {
    if (!graphId || !nodeId) return
    const es = new EventSource(`/api/weave/graph/${graphId}/node/${nodeId}/messages`)
    es.onmessage = (msg) => {
      const evt = JSON.parse(msg.data)
      setMessages((m) => [...m, evt])
      setRunning(evt.running)
    }
    return () => es.close()
  }, [graphId, nodeId])

  async function send() {
    if (!input.trim()) return
    const text = input
    setInput('')
    setMessages((m) => [...m, { role: 'user', text, ts: Date.now() }])
    await fetch(`/api/weave/graph/${graphId}/node/${nodeId}/message`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ text }),
    })
  }

  return (
    <div className="subagent-chat">
      <h3>{nodeId} · 对话</h3>
      <div className="messages">
        {messages.map((m, i) => (
          <div key={i} className={`msg msg-${m.role}`}>
            <b>{m.role}</b>: {m.text}
          </div>
        ))}
      </div>
      <div className="input-row">
        <input
          value={input}
          onChange={(e) => setInput(e.target.value)}
          disabled={!running}
          placeholder={running ? '输入消息给子代理...' : '子代理已结束'}
          onKeyDown={(e) => e.key === 'Enter' && send()}
        />
        <button onClick={send} disabled={!running || !input.trim()}>发送</button>
      </div>
    </div>
  )
}
```

# 问题 4：图在中间环节出错时继续跑

## 4.1 现象

```
dev 产出 develop.md 0 行（失败）
   ↓
test 还在跑（没东西可测）
   ↓
quality 还在跑（没东西可审）
   ↓
整图跑完 30 分钟，浪费大量 token
```

无法暂停；节点失败不传播。

## 4.2 根因

1. **节点没有产物验证**：`node-end` 只看 handler 是否抛错
2. **`quality_gate` 字段从未生效**
3. **图级无失败传播/暂停机制**：PAUSE 依赖文件轮询

## 4.3 修复

### 修复 1：节点级产物验证

**`src/l2-engine/node-validator.ts`**（新建）：

```typescript
export interface ValidationResult {
  passed: boolean
  failures: string[]
}

export function validateNodeOutput(
  patch: Partial<Record<string, unknown>>,
  state: Record<string, unknown>,
  gates: string[],
): ValidationResult {
  const failures: string[] = []
  
  for (const gate of gates) {
    // 简化版 gate 解析：支持 3 种表达式
    if (gate.includes('非空') || gate.includes('必须有')) {
      const artifacts = patch.artifacts as Record<string, string> | undefined
      if (!artifacts || Object.keys(artifacts).length === 0) {
        failures.push(`质量门未过: ${gate}（产物为空）`)
      }
    }
    if (gate.startsWith('tsc') || gate.startsWith('单测')) {
      // 交给 R6 自己保证，引擎不重复跑
    }
    if (gate.match(/至少\s*(\d+)\s*个/)) {
      const match = gate.match(/至少\s*(\d+)\s*个/)
      const required = match ? parseInt(match[1]) : 0
      const artifacts = patch.artifacts as Record<string, string> | undefined
      const count = artifacts ? Object.keys(artifacts).length : 0
      if (count < required) failures.push(`质量门未过: 需要至少 ${required} 个产物，实际 ${count}`)
    }
  }
  
  return { passed: failures.length === 0, failures }
}
```

```typescript
export interface GraphControl {
  pause(): void
  resume(): void
  stop(): void
  isPaused(): boolean
  isStopped(): boolean
  waitForResume(): Promise<void>
}

const controls = new Map<string, GraphControl>()

export function getGraphControl(graphId: string): GraphControl {
  let ctrl = controls.get(graphId)
  if (!ctrl) {
    const state = { paused: false, stopped: false }
    const waiters: Array<() => void> = []
    ctrl = {
      pause: () => { state.paused = true },
      resume: () => {
        state.paused = false
        for (const w of waiters) w()
        waiters.length = 0
      },
      stop: () => {
        state.stopped = true
        for (const w of waiters) w()
        waiters.length = 0
      },
      isPaused: () => state.paused,
      isStopped: () => state.stopped,
      waitForResume: () => new Promise((resolve) => {
        if (!state.paused) resolve()
        else waiters.push(resolve)
      }),
    }
    controls.set(graphId, ctrl)
  }
  return ctrl
}

export function clearGraphControl(graphId: string): void {
  controls.delete(graphId)
}
```

### 修复 2：错误分类

**`src/l2-engine/error-classifier.ts`**（新建）：

```typescript
export interface ErrorClassification {
  reason: PauseReason
  needsUserIntervention: boolean
  details: PauseSnapshot<any>['pauseDetails']
}

export function classifyError(error: Error): ErrorClassification {
  const msg = error.message.toLowerCase()
  
  if (msg.includes('permission') || msg.includes('operation not permitted') || msg.includes('sandbox')) {
    return {
      reason: 'permission-denied',
      needsUserIntervention: true,
      details: {
        error: error.message,
        deniedOperation: extractOperation(error.message),
        requiredPermission: 'workspace-write beyond session workspace',
        suggestedAction: '授权后重试，或跳过该节点',
      },
    }
  }
  
  if (msg.includes('not found') || msg.includes('not installed') || msg.includes('command not found')) {
    return {
      reason: 'dependency-missing',
      needsUserIntervention: true,
      details: {
        error: error.message,
        suggestedAction: '安装缺失依赖后恢复',
      },
    }
  }
  
  if (msg.includes('token') || msg.includes('budget') || msg.includes('exceeded')) {
    return {
      reason: 'budget-exceeded',
      needsUserIntervention: true,
      details: {
        error: error.message,
        suggestedAction: '追加预算后恢复',
      },
    }
  }
  
  if (msg.includes('timeout')) {
    return {
      reason: 'timeout',
      needsUserIntervention: true,
      details: { error: error.message, suggestedAction: '延长超时或终止' },
    }
  }
  
  return {
    reason: 'tool-error-fatal',
    needsUserIntervention: true,
    details: { error: error.message, suggestedAction: '检查后恢复' },
  }
}

function extractOperation(msg: string): string | undefined {
  const m = msg.match(/(write|read|execute)\s+(\S+)/)
  return m ? `${m[1]} ${m[2]}` : undefined
}
```

export async function resumeGraphRealTool(ctx, graphId, options) {
  const root = getArtifactsRoot(graphId)
  const snapshot = await readPauseSnapshot(root, graphId)
  if (!snapshot) return { ok: false, message: `未找到 graph ${graphId} 的暂停快照` }

  const spec = getGraph(graphId)?.spec
  if (!spec) return { ok: false, message: `graph ${graphId} 未注册` }

  const graph = createStateGraph(ctx, spec.maxIterations ?? 25, 4, root, ...)
  // ... 节点/边注册 ...

  // 用户补充上下文先发给暂停节点
  if (options.additionalContext && snapshot.childSessions[snapshot.pausedNode]) {
    const childId = snapshot.childSessions[snapshot.pausedNode]
    await ctx.subagents.sendMessage(parent, childId,
      [{ type: 'text', text: `[用户补充]\n${options.additionalContext}\n\n请继续。` }], {})
  }

  const resumeFrom = options.skipNode 
    ? getNextNode(spec, snapshot.pausedNode)
    : snapshot.pausedNode

  graph.run(
    { ...snapshot.state, ...(options.modifyState ?? {}) },
    {
      checkpoint, graphVersion: spec.graphVersion,
      graphSchemaHash: spec.graphSchemaHash,
      graphId,
      initialIteration: snapshot.iteration,
      initialLoopUsage: snapshot.loopUsage,
      startFrom: resumeFrom,
      restoredChildSessions: snapshot.childSessions,
      completedNodes: snapshot.completedNodes,
      agent: parent,
    },
  ).then((r) => ctx.logger.info('weave', '恢复后执行结束', { graphId, success: r.success }))
   .catch((e) => ctx.logger.error('weave', '恢复失败', e))

  await removePauseSnapshot(root, graphId)
  return { ok: true, graphId, resumeFrom, status: 'resumed' }
