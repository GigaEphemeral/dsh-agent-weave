# 隔离环境启动手册（test-env）

> 版本：v1（2026-09-22）｜目标读者：开发者/复验者
> 原则：**隔离 DSH_HOME 运行，主环境（`D:\dsharness\data`）零写入**；
> 测试数据保留不清理；每步给可复制命令。

## 一、环境基线（本机实测）

| 项 | 值 |
|---|---|
| DSH | 0.1.5-rc.2（dsh bin 不在 PATH，用完整路径调用） |
| dsh bin 路径 | `%USERPROFILE%\.dsh\profiles\node_modules\@deepseek-ai\dsh\lib\bin.js` |
| 隔离 DSH_HOME | `<项目>\3pluginCode\test-env\dsh-home` |
| profiles | `weave-test`（web）/ `weave-headless`（headless 一次性任务） |
| mock LLM | harness 源码 `packages/test-support/llm-mock-server`（OpenAI 兼容） |
| 真实 LLM | 火山引擎 llm-pi-ai（`huoshan-186`，key 走环境变量注入） |

> PowerShell 注意：`$home` 是内置只读变量，设 DSH_HOME 用别的变量名。

## 二、快速启动（mock LLM 模式，无真实 key 依赖）

### 2.1 启动 mock LLM server

```powershell
# 简单模式：固定成功文本
node -e "
import('file:///D:/dsharness/sof/deepseek-harness/packages/test-support/llm-mock-server/lib/index.js').then(async ({ startMockLlmServer }) => {
  const s = await startMockLlmServer({
    port: 17999, apiKey: 'mock-key',
    sequence: ['success'], repeatLast: true,
    successText: '【mock 响应】确定性内容。',
  });
  console.log('MOCK_READY', s.baseURL);
  setInterval(() => {}, 1000);
})"
```

```powershell
# 端到端模式：主 Agent 先 tool_call 调 weave_run_chain，之后 6 个子代理各一次 success
node -e "
import('file:///D:/dsharness/sof/deepseek-harness/packages/test-support/llm-mock-server/lib/index.js').then(async ({ startMockLlmServer }) => {
  const s = await startMockLlmServer({
    port: 17999, apiKey: 'mock-key',
    sequence: ['tool_call_success','success','success','success','success','success','success'],
    repeatLast: true,
    toolName: 'weave_run_chain',
    toolArguments: JSON.stringify({ user_input: '做一个计算器命令行工具' }),
    successText: '【角色产出】确定性交付物内容。',
  });
  console.log('MOCK_READY', s.baseURL);
  setInterval(() => {}, 1000);
})"
```

### 2.2 隔离 settings 指向 mock

`test-env/dsh-home/settings.yaml` 的 `llm-pi-ai.providers.huoshan-186`：

```yaml
huoshan-186:
  displayName: mock-llm
  apiKeyEnv: MOCK_LLM_API_KEY
  api: openai-completions
  baseURL: http://127.0.0.1:17999/v1
  models:
    - id: DeepSeek-V4-Flash
      name: deepseek-v4-flash
      contextWindow: 1000000
      maxTokens: 256000
```

> 备份：mock 版 settings 已存为 `settings.yaml.mock.bak`。

### 2.3 打包并安装插件到隔离 profile

```powershell
$dshHome = '<项目>\3pluginCode\test-env\dsh-home'
$env:DSH_HOME = $dshHome
$dshBin = "$env:USERPROFILE\.dsh\profiles\node_modules\@deepseek-ai\dsh\lib\bin.js"

# 在项目目录打包（lib 全量 + cordis.patch.yml + roles + skills）
pnpm build && pnpm pack --pack-destination ./dist

# 安装到两个 profile（remove 再 add 强制刷新）
node $dshBin plugin --profile weave-headless remove dsh-agent-weave
node $dshBin plugin --profile weave-headless add "<项目>\3pluginCode\dist\dsh-agent-weave-0.1.0.tgz"
node $dshBin plugin --profile weave-test remove dsh-agent-weave
node $dshBin plugin --profile weave-test add "<项目>\3pluginCode\dist\dsh-agent-weave-0.1.0.tgz"
```

> 关键：`package.json` 的 `dsh.bundle` 必须是 `{ patch: "./cordis.patch.yml" }` 对象；
> `files` 必须含整个 `lib` 目录（否则子模块缺失导致 boot 失败）。

### 2.4 运行验证

```powershell
# ① 角色注册冒烟（headless 简单任务）
$env:MOCK_LLM_API_KEY = 'mock-key'
node $dshBin --profile weave-headless "只回复：收到"
# 预期：日志见 6 角色注册（inherits_parent_context=false），输出「收到」

# ② 端到端单链（mock 模式，固定文本）
node $dshBin --profile weave-headless "请调用 weave_run_chain 工具执行单链，user_input 为 '做一个计算器'"
# 预期：R1→R8 六阶段 completed，productions/<角色ID>/ 6 个文件

# ③ web 门禁（chat 可见节点）
node $dshBin --profile weave-test --no-open --port 0   # 随机端口，日志见 http://127.0.0.1:<port>
# 浏览器打开该 URL 发消息，观察子代理节点树
```

## 三、真实 LLM 模式（需要 API key）

### 3.1 获取 key（从主 DSH credentials 服务，不落盘）

```powershell
$creds = Get-Content "D:\dsharness\data\.credentials.yaml" -Raw
$key = [regex]::Match($creds, 'HUOSHAN_186_API_KEY:\s*(\S+)').Groups[1].Value
$env:HUOSHAN_186_API_KEY = $key   # 仅注入进程环境，不写文件
```

### 3.2 切换 settings 到真实端点

`test-env/dsh-home/settings.yaml` 的 `huoshan-186` 改为：

```yaml
huoshan-186:
  displayName: huoshan-186
  apiKeyEnv: HUOSHAN_186_API_KEY
  api: openai-completions
  baseURL: https://ark.cn-beijing.volces.com/api/plan/v3
  models:
    - id: DeepSeek-V4-Flash
      name: deepseek-v4-flash
      contextWindow: 1000000
      maxTokens: 256000
```

### 3.3 主 Agent 默认模型路由（headless）

`test-env/dsh-home/profiles/weave-headless/cordis.patch.yml`：

```yaml
- id: agent-default-model
  config:
    provider: huoshan-186
    model: DeepSeek-V4-Flash    # 必须用 ID（llm-pi-ai 按 ID 解析）
```

### 3.4 运行

```powershell
# 冒烟（简单任务）
node $dshBin --profile weave-headless "只回复：收到"

# 端到端（真实 LLM，每阶段 3-15 分钟不等，建议后台运行）
node $dshBin --profile weave-headless "请调用 weave_run_chain 工具执行单链，user_input 为 '做一个简单的项目介绍 web 页面，阐述其原理与架构，并配一张数据流转图'"
```

> 真实 LLM 观察点：每个角色会真实读取上游文件、探索目录（R2/R4 有多个
> read/glob/pwsh 工具调用）；R4 详细设计可能耗时 10+ 分钟（长输出）。

## 四、常见问题

| 症状 | 原因 | 解决 |
|---|---|---|
| boot 报 `Cannot find module lib/l3-roles/...` | `files` 未含整个 lib | `files` 写 `"lib"` 整目录 |
| boot 报「declares no dsh.bundle」 | `dsh.bundle` 是字符串 | 改为 `{ patch: "./cordis.patch.yml" }` |
| boot 报「non-object dsh.client declaration」 | `dsh.client` 是字符串 | 改为 `{ platform: "web" }` |
| 主 Agent 报 `UNKNOWN_MODEL: ... deepseek-v4-flash` | 模型写成了 name | 用 ID：`DeepSeek-V4-Flash` |
| 角色报 `UNKNOWN_MODEL` | 角色 YAML 的 model 是 name | 改为 ID `DeepSeek-V4-Flash` |
| 角色目录读取失败 | rolesDir 解析到错误位置 | 默认基于插件包根，勿依赖 cwd |
| pnpm 链接失效（node 找不到 @deepseek-ai/x） | pnpm 12 Windows 哈希目录 | 跑 `test-env/fix-pnpm-links.mjs` |
| 中文乱码 | PowerShell 控制台编码 | `[Console]::OutputEncoding = UTF8`；文件本身是 UTF-8 正确 |
